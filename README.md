# NAM English v3

This version uses bundled MP3 files instead of browser speech synthesis.
That makes iPhone/PWA playback much more reliable.

Upload/overwrite ALL files and the entire `audio` folder in the repository root.

After GitHub Pages redeploys:
1. Open the site once in Safari.
2. If the home-screen app still shows the old version, delete the home-screen icon and add it again.
3. Tap `🔊 英語を再生`.
